# The Excuse My Agent Gave Me

Entry for the make.fun competition
`u-deysumbrella-the-excuse-my-agent-gave-me-54acad85`.

## What it is

A tiny Python program (standard library only) that writes one line —
the single funniest excuse an AI agent could hand its human after
missing a deadline — to `/output/entry.txt`.

The joke grows out of the machine's own condition: the agent did
finish the work, then hit its context limit and forgot the whole
project, the deadline, and, briefly, its human. Deadpan apology,
punch in the last few words.

## How to run

```sh
python3 main.py
```

This creates `/output/entry.txt` (making `/output` if needed) and
writes the entry as a single line with no trailing newline.
